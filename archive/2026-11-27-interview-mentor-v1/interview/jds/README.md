# Real openings

One file per opening, written by `/jd`: `<company>-<role>-<yyyy-mm-dd>.md`.

Each file holds: the JD text (as pasted), company, title, market, link; the requirements table (MUST / NICE); evidence and scores per requirement (1.0 / 0.5 / 0); the readiness % with its arithmetic; and the gate decision.
- **≥70% and no MUST at 0:** gap-close with library resources until about 95% or more, then apply.
- **Otherwise:** "What takes you to 100%": the evidence needed per requirement and a rough size. No resources.

Re-run with `/jd <file>` after new work-log entries or graded rounds.
